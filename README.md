# Owen

个人介绍 / 简历站。Next.js（App Router）+ TypeScript + Tailwind CSS，深色编辑式排版。

文案来自个人简历，集中在 [`src/lib/content.ts`](src/lib/content.ts)。站点不读取环境变量，也不需要密钥。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

## 构建

```bash
npm run build
npm start
```
